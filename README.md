# Кызмат

MVP сервиса для поиска проверенных мастеров в Бишкеке.

Пользователь может выбрать услугу, описать задачу, указать район и бюджет, сравнить специалистов, посмотреть их работы и отзывы, а затем написать мастеру в чат.

## Демо

[Открыть опубликованный MVP](https://dastankt.github.io/kyzmat-mvp/)

## Файлы проекта

- `index.html` — интерактивный MVP и главная страница GitHub Pages.
- `pitch-deck-new.html` — основной питч-дек.
- `pitch-deck.html` — первая версия питч-дека.
- `Сценарий выступления Кызмат.txt` — текст пятиминутного выступления и ответы на вопросы жюри.

## Запуск локально

Откройте `index.html` в браузере. Установка зависимостей не требуется.

## Статус

Проект создан как MVP для демонстрации на хакатоне. Профили мастеров, отзывы и ответы в чате используются как демонстрационные данные.
